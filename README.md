# Simple Interest Calculator

A web-based simple interest calculator built with HTML, CSS, and JavaScript.

## Features

- Calculate simple interest based on principal, rate, and time
- Clean dark-themed UI with responsive design
- Displays total amount and future year of maturity

## Formula

```
Simple Interest = (Principal × Rate × Time) / 100
Total Amount = Principal + Simple Interest
```

## How to Use

1. Enter the **Principal Amount**
2. Enter the **Annual Rate of Interest**
3. Enter the **Time in Years**
4. Click **Compute Interest** to see the result

## Technologies Used

- HTML5
- CSS3
- JavaScript
